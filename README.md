# Alex Kutkin's site

This is my personal site. I write notes here and keep my CV.

Live: <https://alexkutkin.github.io/>

Built with [Astro](https://astro.build/).

## Run it locally

You need Node and npm.

```sh
npm install
npm run dev
```

Then open <http://localhost:4321/>.
