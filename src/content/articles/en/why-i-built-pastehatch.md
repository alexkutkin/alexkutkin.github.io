When you work with an AI agent, you often need to give it materials for a task: a screenshot, a few files, a link, some notes. I built PasteHatch to collect all of that in one place.

It's a small Windows app. It has baskets, which are ordinary folders on disk. You can drag files into a basket, paste a screenshot or a link, or write a note. Everything is saved to the folder straight away.

Then you copy the path and give it to the agent. If it can read local files, it can open the materials itself and work with them. For example, you can collect screenshots of a bug and add a short note about what needs fixing.

I like that the contents of a basket remain ordinary files. You can open the folder in File Explorer, see what's there and add something by hand. The app stores the materials locally.

I'll keep working on PasteHatch. For now, it solves one straightforward problem: collecting the materials you need for a task with an agent.
