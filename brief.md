- Создаём личный сайт: главную со списком статей, страницу статьи и страницу «Обо мне». Отдельные страницы архива и проектов сейчас в объём не входят.
- Визуальный источник требований — [актуальный макет Penpot](https://design.penpot.app/#/workspace?team-id=4b7520f4-628e-8193-8008-d500e9d44886&file-id=eaccfa4c-8a01-81ad-8008-d5018d25d65c&page-id=eaccfa4c-8a01-81ad-8008-d5018d25d65d). При подготовке дизайна нужно прочитать его актуальное состояние; тексты прежнего прототипа не подтверждают биографические факты.
- Сайт статический: Astro, Markdown и обычный CSS. Сборка выполняется через Node и npm.
- После создания технического каркаса сайта остановить дальнейшую реализацию и выполнить [verification](../../../Users/kutki/.agents/skills/verification/SKILL.md) в режиме Create, чтобы создать локальный скилл проверки проекта и карту возможностей. Этот шаг выполняется после появления работающего каркаса.
- Для проверки сайта можно использовать предоставленный Docker-контейнер с открытыми портами, доступный через Git Bash в Windows, вне WSL. Перед использованием проверить фактический доступ, контейнер и порты; доступ пока не проверен.
- Публикация выполняется через GitHub Actions на GitHub Pages по адресу [alexkutkin.github.io](https://alexkutkin.github.io/); [репозиторий сайта](https://github.com/alexkutkin/alexkutkin.github.io).
- Английский — основной язык сайта, русский — второстепенный. Все страницы, включая каждую статью, доступны на обоих языках; английский перевод готовится сразу к публикации.
- Языковые версии статьи хранятся в отдельных Markdown-файлах и связываются общим translationKey. Переключатель языка ведёт на перевод текущей страницы; английские переводы статей готовит агент.
- На главной статьи показываются от новых к старым, по 10 на страницу, с обычными ссылками пагинации. Теги, фильтрация и поиск в текущий объём не входят; используем [пагинацию Astro](https://docs.astro.build/en/guides/routing/#pagination).
- Для английской и русской версий доступны отдельные RSS-ленты с полным текстом статей через [Astro RSS](https://docs.astro.build/en/recipes/rss/). Для Mermaid в RSS показываются исходник и ссылка на статью.
- Markdown поддерживает заголовки, списки, цитаты и блоки кода.
- Локальные изображения обрабатываются средствами Astro; поддерживаются альтернативный текст и подписи.
- Широкие таблицы, блоки кода и диаграммы прокручиваются внутри своего блока; текст статьи переносится по ширине страницы.
- Для разработки нужен тестовый набор из 11 статей, каждая с английской и русской версиями. Одна статья подробно проверяет сложную вёрстку и переходы; остальные 10 наполняют список и могут содержать Lorem ipsum вместо полноценных текстов.
- Сложная тестовая статья проверяет разбор Markdown: несколько уровней заголовков, оглавление с якорями, вложенные списки, цитаты, таблицу, широкое изображение с подписью, длинные ссылки, блоки кода с длинными строками и Mermaid — корректную и намеренно ошибочную для проверки резервного исходника. На ней проверяются узкие экраны, обычная навигация и переключение языка; отдельные анимации переходов не требуются.
- Все 11 тестовых статей с переводами хранятся в Git и работают через обычную сборку, пагинацию и RSS. Перед релизом удаляем их.
- Диаграммы Mermaid отображаются читаемо на странице. При ошибке отображается исходный код диаграммы.
- Страница «Обо мне» содержит краткую профессиональную биографию и описания PasteHatch и Herdr Tray из актуального Penpot. Сведения должны быть подтверждены перед публикацией.
- [Telegram @alxt](https://t.me/alxt) — основной контакт на странице «Обо мне»; он должен быть заметнее дополнительных ссылок. Там же размещаются [GitHub](https://github.com/alexkutkin), [X](https://x.com/alex_kutkin) и резюме (источник не публикуется); адреса взяты из актуального Penpot.
- Фотография появляется на сайте только после получения реального портрета.
- Все факты в публикационных статьях и биографии должны быть реальными и подтверждёнными. Тестовые статьи явно обозначаются как демонстрационные материалы; Lorem ipsum и технические примеры не представляются как реальные сведения об авторе.
- Оформление из актуального Penpot напрямую реализуется в обычном every-layout-grid.css, который служит главным источником стилей. В начале файла находятся CSS-переменные цветов, типографики, размеров и интервалов, затем минимальный набор нужных сайту примитивов раскладки.
- КРИТИЧНО: сайт строится на подготовленной и отревьюенной [сетке и шкале отступов](./references/every-layout-grid.css); из Penpot сохраняются композиция, порядок элементов, взаимное расположение, колонки и визуальная иерархия, а конкретные отступы выбираются из этой шкалы и раскладка собирается её примитивами. Правило действует и внутри компонентов: исключение допустимо только в крайнем случае, когда средствами сетки задачу нормально не решить, и требует явного обоснования.
- Слой раскладки следует принципам [Every Layout](https://every-layout.dev/): естественные размеры, гибкие сетки и перенос по доступному месту. [Локальный CSS-пример](./references/every-layout-grid.css) служит ориентиром, а состав примитивов выбирается под сайт без переноса всего файла.
- Страницы адаптируются для компьютеров и мобильных экранов преимущественно средствами Every Layout. Медиазапросы используются минимально и обоснованно: для предпочтений пользователя и поведения, которое нельзя удобно выразить естественной раскладкой.
- Сайт поддерживает светлую и тёмную темы с выбором «Системная / Светлая / Тёмная». По умолчанию применяется настройка устройства через [prefers-color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme); явный выбор сохраняется и применяется до показа страницы, а палитры задаются CSS-переменными.
- Навигация доступна с клавиатуры. Фокус и выбранная страница визуально различимы.
- Перед публикацией проверяются сборка, обе языковые версии, переключение языков, Markdown и Mermaid с резервным исходником. Также проверяются пагинация, RSS, обе темы, клавиатурная навигация, адаптивная раскладка, изображения, прокрутка широких блоков и удаление тестовых статей перед релизом.
- Корневой адрес / перенаправляет на основную английскую версию /en/. Русская версия доступна по /ru/.
